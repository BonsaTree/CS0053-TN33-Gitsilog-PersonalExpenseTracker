# Personal Expense Tracker

A terminal-based C++ Expense Tracker for users to monitor their daily expenses.



## Authors

- [@BonsaTree](https://www.github.com/BonsaTree)
- [@shanamarisntg](https://www.github.com/shanamarisntg)
- [@roselynrv](https://www.github.com/roselynrv)

## Features

- Add expenses (date, amount, category, description)
- View existing expenses, sorted by entry order, date, or category, with totals
- Search expenses by date, category or amount.
- Edit existing expenses.
- Save and load to a file named expenses.txt

## Required Compiler
g++ (MinGW-w64) with C++17 support

## Compile and Run
```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o app.exe
./app.exe
```
